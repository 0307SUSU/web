### 提交git时忽略指定文件或文件夹
> 创建.gitignore文件，在文件中指定要忽略的文件或文件夹

### 撤回git操作
> reset（英文中有重置的意思）、
> checkout（英文中有检验的意思）、
> revert（英文中有恢复的意思）、
> reflog（ref在英语中有参考的意思，log有日志的意思，这里的reflog意思是参考之前的操作日志）
> HEAD（英文中有头部的意思，这里的HEAD代表指针， 是一个指向当前分支最新提交的引用。）

- 撤销提交
```bash
git revert # revert在英文中有恢复的意思，在这里的作用就是恢复到上一次远程提交之前（注意此命令是恢复远程提交的）

```
